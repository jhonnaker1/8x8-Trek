# The dedication line under the author's credit.
82	TO THE MSX2.

# THE FAREWELL. The C128's says "BASIC IS ON THE 40-COLUMN SCREEN", and this
# machine has neither. What happens is measured, not assumed: the game is the
# boot disk's COMMAND2.COM, so plat_exit's _TERM0 makes MSXDOS2.SYS load the
# shell again -- which is the game. The title was back 25 seconds after the
# quit in `make gameshot`. main() waits for a key first, so the line says so.
10	HIT A KEY AND THE GAME RESTARTS.
